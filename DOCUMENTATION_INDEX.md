## 🎨 Design System at a Glance

### Color Scheme
```
Primary: Blue → Purple → Pink
Background: #0a0a0a (Zinc-950)
Text: #e8e8e8 (Zinc-100)
Accent: Blue-600 to Purple-600
```

### Typography
- Display: Cormorant Garamond (serif, italic)
- Body: DM Sans (sans-serif)

### Spacing
- Grid: 8px multiples
- Components: 24px padding
- Sections: 32px padding

### Animations
- Fade-up on scroll
- Smooth hover effects
- Gradient transitions
- Staggered elements
